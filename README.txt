ЧТО И ГДЕ МЕНЯТЬ
src/content.mjs — тексты RU/TR, телефон, Telegram, адрес сайта, порядок дней, список фотографий.
public/assets/styles.css — оформление и адаптация под телефоны.
public/assets/site.js — меню, галереи, переключение языка, копирование телефона.
public/assets/photos/ — оптимизированные фотографии.
public/assets/photo-credits.json — первоисточники, авторы и лицензии.
scripts/build.mjs — сборка конечного HTML без серверной части.
dist/ — готовая папка для размещения на статичном хостинге.
output/advertising/ — рекламные изображения, тексты публикаций и промпты.
output/qa/ — результаты технической и браузерной проверки и скриншоты.

ЛОКАЛЬНЫЙ ЗАПУСК
В папке проекта выполнить:
1. npm install
2. npm run build
3. npm run preview
Открыть http://127.0.0.1:4173/ru/ или /tr/.
Для просмотра сайт нужно запускать через HTTP; открытие HTML двойным кликом не поддерживает абсолютные ссылки /assets/.
Изменив исходные тексты или CSS, выполнить npm run build и обновить страницу.

ПРОВЕРКА
npm run check — локальные ссылки, метаданные языков, контакты, подписи изображений, полнота авторства.
node scripts/browser-check.mjs — браузерная проверка в установленном Microsoft Edge.
Браузерная проверка рассчитана на Windows и путь Edge, указанный в скрипте.

ПУБЛИКАЦИЯ НА ДРУГОМ ХОСТИНГЕ
Изменить settings.origin в src/content.mjs на свой домен, выполнить npm run build и загрузить содержимое dist/ в корень сайта.
Сохранить структуру папок ru/, tr/ и assets/.
Файл .openai/hosting.json содержит привязку к созданному Sites-проекту; не переносите его в новый независимый Sites-проект как чужой идентификатор.
